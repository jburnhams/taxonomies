## What is distinctive

The most used method for building a taxonomy in information systems research: iterate between concepts and cases until stated ending conditions hold.

## Notes

- A taxonomy is a set of **dimensions**, each with **characteristics** that are mutually exclusive and collectively exhaustive: every object has exactly one characteristic per dimension. (This is a faceted classification under another name.) *Formal definition from prior knowledge; check.*
- Start with a **meta-characteristic**, "derived from the purpose and target users of the taxonomy" (quoted by Kundisch).
- Then loop: either **empirical-to-conceptual** (take real objects, find their shared characteristics, group into dimensions) when you have data, or **conceptual-to-empirical** (propose dimensions from theory, test on objects) when you already understand the field.
- Stop when the **ending conditions** hold. Subjective: "concise, robust, comprehensive, extendible, and explanatory". Objective (prior knowledge, check): all objects examined; no object merged or split in the last round; at least one object per characteristic; no new dimensions or characteristics added in the last round; every dimension unique, no duplicate characteristics within a dimension; each cell (combination) unique.
- 123 of 160 IS taxonomy papers reviewed by Kundisch et al. used it.
