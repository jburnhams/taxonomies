## What is distinctive

Boundary objects: how groups with different vocabularies still work together.

## Notes

- Boundary objects are "plastic enough to adapt to local needs ... yet robust enough to maintain a common identity across sites". Specimens, forms and standardised methods let amateurs, collectors and scientists cooperate without sharing one worldview. *(Quote from prior knowledge.)*
- For us: the shared kernel of cross-domain terms should be a boundary object: loosely defined at the top, refined per domain.
