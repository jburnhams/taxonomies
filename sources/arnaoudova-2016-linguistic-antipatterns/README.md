## What is distinctive

A catalogue of names that lie: names that promise something the code does not do.

## Notes

- Seventeen linguistic antipatterns, such as a `get` method that does not return, an `is` method that returns more than a boolean, a plural name holding one item.
- Developers judged most of them poor practice. A taxonomy's names can lie in the same ways (a term whose name implies a scope its definition does not have).
