## Notes

- Resampling 168 participants: about 15 participants gave results correlating about 0.90 with the full set; 20-30 reached about 0.93-0.95. *(From prior knowledge; check.)*
- Nielsen's rule of thumb follows: 15 users for card sorting. For a one-person project the equivalent is two or more independent sorters (Jonathan plus models) and an agreement measure.
