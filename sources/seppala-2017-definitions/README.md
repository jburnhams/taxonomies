## What is distinctive

Rules for writing the definition of a term, so it can be checked.

## Notes

- **Genus-differentia**: "A definition should have the genus-differentia form": *an A is a B that C*. Example: mammal: "a vertebrate that has hair, gives live birth, and nurses its young". Exactly one genus, the nearest one (genus proximus); no "type of" or other categorizers; no "and"/"or" in the genus.
- Necessary and, where possible, jointly sufficient conditions; no encyclopaedic extras, no negative terms, no definition by listing members.
- Neither too broad nor too narrow; one thing per definition; **no circularity**; features that can all be true together.
- Avoid "usually", "generally"; keep examples out of the definition (put them in a separate example field). *(From the summary: avoid deictic terms, subjective statements; define abbreviations; match the text to any logical definition.)*
