## What is distinctive

Three hundred years of practice at keeping names stable while the classification underneath keeps changing.

## Notes

- **Nomenclature is separate from taxonomy.** The codes govern which name a group bears, not how you classify. Scientists are free to reclassify; the codes then tell you what the group is called.
- **Types**: every name is anchored to a type (a specimen for a species, a species for a genus). If a group is split, the name stays with the part that holds the type. This makes a name point at a thing, not at a description.
- **Priority**: the oldest validly published name wins. Later names become synonyms. Stability beats aptness.
- **A name is a label, not a description.** A name is not rejected for being inappropriate (a species named for the wrong place keeps its name).
- **Homonyms** are forbidden within a code: one name, one taxon.
- Starting points (Linnaeus 1753 for plants, 1758 for animals) stop endless digging into older names.
- For us: give each term a stable identity and a type example; let the definition and classification move while the anchor holds; prefer keeping an established name to finding a better one.
