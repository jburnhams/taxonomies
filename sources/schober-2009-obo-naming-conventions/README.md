## Notes

Table 1, "The initial set of OBO Foundry naming conventions":
- **1 Be clear and unambiguous.** 1.1 explicit and concise names, omit articles; 1.2 context-independent names, no truncations or colloquialisms; 1.3 avoid "taboo words" (affixes that make claims about the term, e.g. "protocol class" instead of "protocol"); 1.4 no administrative metadata in names.
- **2 Be univocous.** 2.1 one meaning per name, no homonyms; 2.2 avoid conjunctions ("'and' and 'or' should be avoided"); 2.3 singular nominal form; 2.4 positive names, no negations; 2.5 avoid catch-all terms ("rag-bag" words such as 'unknown', 'unclassified').
- 3 Reduce string variance (recycle strings; genus-differentia style names; spaces as separators; expand abbreviations and symbols) and 4 Typography (lower-case beginnings; no character formatting). *Sections 3-4 from a summary, check before citing.*
- For us: these become the naming rules in the design almost as they stand.
