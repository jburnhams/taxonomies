## What is distinctive

The classic measurement of how rarely people choose the same word for the same thing.

## Notes

- Across five domains (text-editing commands, recipes, classified ads, and others), two people chose the same term for an object with probability **under 0.20** (commonly quoted as 0.07 to 0.18). Wikipedia's secondary summary: different people name the same thing differently about 80% of the time.
- "Armchair" naming (a designer picking the one obvious word) does badly. Allowing **many aliases** per object raises the chance of a match a lot, which is the paper's recommendation ("unlimited aliasing", with care about ambiguity). Exact alias counts and hit rates: check in the paper.
- For us: the preferred name is a convention you must agree and write down; you will not get agreement by everyone picking "the obvious name". Record the other names people reach for as aliases.
