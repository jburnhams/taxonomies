## What is distinctive

A formal model of good identifier naming: names and concepts should map one to one.

## Notes

- **Consistent**: each concept has one name (no synonyms) and each name one concept (no homonyms), within a program.
- **Concise**: a name says exactly what the concept is, not something broader.
- Proposes keeping an explicit identifier dictionary (name, concept, type) to check both. This is a controlled vocabulary for code, and the same rule SKOS states as "one preferred label per language".
