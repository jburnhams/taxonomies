## What is distinctive

Measured cost of abbreviations: readers found defects faster with word names than with letters or abbreviations.

## Notes

- Professional developers found semantic defects faster in code with full-word names than with abbreviations or single letters (roughly a fifth faster; check the exact figure).
- Supports "no abbreviations" in a vocabulary's preferred labels.
