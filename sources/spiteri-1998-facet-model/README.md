## What is distinctive

Ranganathan's canons cut down to a checklist you can apply to a draft facet.

## Notes

Principles for choosing facets (the idea plane), as Denton gives them:
- **Differentiation**: a facet must divide its things into at least two groups.
- **Relevance**: the facet reflects the purpose of the scheme.
- **Ascertainability**: you can tell which value applies.
- **Permanence**: the characteristic does not change while the thing exists.
- **Homogeneity**: each facet "must represent only one characteristic of division".
- **Mutual exclusivity**: values within a facet do not overlap.
- **Fundamental categories**: no single set (PMEST, CRG's 13) is required; use what the domain needs.
Verbal plane: **context** (a term's meaning comes from its place in the scheme) and **currency** (use current words).
