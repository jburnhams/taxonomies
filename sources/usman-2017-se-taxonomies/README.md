## What is distinctive

The software-engineering counterpart to Nickerson: how SE builds taxonomies, and a method for doing it better.

## Notes

- Mapped 270 SE taxonomy papers (figure from prior knowledge; check): most were hierarchies, most did not explain how they were built, and few were validated.
- Proposes a 13-step method in four phases: planning (context, unit of classification, classification structure type, procedure, data collection), identification and extraction, design and construction, validation.
- Useful for us because it treats choosing the structure (hierarchy, tree, paradigm, facets) as an explicit step, citing Kwasnik.
