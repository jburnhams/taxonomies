## What is distinctive

The most practical short guide to building a faceted classification; the procedure our design borrows.

## Notes

Seven steps (verbatim headings):
1. **Domain collection**: gather a representative sample of the things.
2. **Entity listing**: list them and break each description into basic concepts.
3. **Facet creation**: group the concepts into facets that are mutually exclusive and jointly exhaustive.
4. **Facet arrangement**: order the values inside each facet, and test-classify.
5. **Citation order**: fix a default order for combining facets.
6. **Classification**: classify the whole domain.
7. **Revision, testing, and maintenance.**
Uses Spiteri's principles as the test for a good facet, and says the values should be a controlled vocabulary. Also summarises Kwasnik (1999) on hierarchies, trees, paradigms and facets, with page references.
