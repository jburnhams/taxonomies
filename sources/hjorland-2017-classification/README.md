## What is distinctive

The pragmatist account of classification: no neutral classification exists; every scheme serves some purpose and view.

## Notes

- Classifications embody theories and interests; the question is which purpose a scheme serves, not whether it is "natural".
- For us: write the purpose down first (the meta-characteristic), and judge the taxonomy against it.
