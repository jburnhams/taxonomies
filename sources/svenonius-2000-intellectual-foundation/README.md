## What is distinctive

The theory behind controlled vocabularies and bibliographic description: why vocabulary control exists and what it costs.

## Notes

- Vocabulary control exists to solve two problems: one thing with many names (synonymy) and one name for many things (homonymy).
- Describes the "bibliographic languages" (works, subjects) as languages with a vocabulary, semantics and syntax, which is the frame we use for a domain vocabulary.
