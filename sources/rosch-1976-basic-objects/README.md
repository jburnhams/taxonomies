## Notes

- The experimental evidence for the basic level summarised in the 1978 chapter: attribute listing, motor programs, shape similarity, recognition speed, children's sorting and naming.
- A finding worth remembering: for biological categories, the basic level for these (American student) subjects sat one level above the folk-biology generic (tree, not oak). Expertise moves the basic level down: experts name at a finer level. So "basic" depends on who the names are for.
