## What is distinctive

Turned Ranganathan into a practical procedure for building small special-purpose faceted schemes, the kind we want per domain.

## Notes

- The CRG argued (1955) that facet analysis should be "the basis of all methods of information retrieval".
- Vickery's 13 fundamental categories (as given by ISKO): substance (product), organ, constituent, structure, shape, property, object of action (patient, raw material), action, operation, process, agent, space, time. A longer, more domain-neutral checklist than PMEST: when a domain's facets are not obvious, walk this list and ask "does this domain have one of these?".
- Special schemes for one subject field, built bottom-up from the field's literature (literary warrant), are the CRG's model. That matches "one taxonomy per domain".
- Vickery himself tested a faceted scheme in the Cranfield retrieval experiments, where it did worse than simple Uniterm indexing (73.8% vs 82.0% recall, per the ISKO entry; second-hand, from the part of the page read only as a summary). Facets help people browse and think; they did not win on retrieval.
